# v1.1.16 Performance Comparison

Synthetic local benchmark comparing before/after strategies.

Command:

```bash
python3 scripts/perf_compare.py \
  --json-output docs/perf/2026-02-06-v1.1.16-bench.json \
  --markdown-output docs/perf/2026-02-06-v1.1.16-bench.md
```

Workload parameters:
- `/status`: 50,000 rows, 300 rounds, 150us/query simulated roundtrip overhead
- First download: 30 rounds, local HTTP with 18ms/request latency, audio=6MB, cover=4MB
- Peak memory: 12 rounds, measured via `tracemalloc`

Notes:
- "Before" models the pre-optimization strategy (3 status queries + double cover fetch in both mode).
- "After" models the v1.1.16 strategy (single status query + single cover fetch with local thumbnail derivation).
- Results are synthetic and intended for relative comparison/regression tracking.
